# 🏥 HealthPulse — Healthcare Portal & Appointment Booking System

HealthPulse is a responsive web application built with React and TypeScript. It provides a seamless interface for managing doctor appointments, tracking patient queues, and switching across multiple languages.

---

## ✨ Features

- 👨‍⚕️ **Role-Based Dashboards**: Separate views and functionalities for Patients and Doctors.
- 📅 **Appointment Booking System**: Book, view, and manage medical appointments in real-time.
- ⏱️ **Queue & Wait-Time Tracking**: Queue positions and estimated wait times.
- 🌍 **Multi-Language Support**: Switch languages dynamically between English (EN), Tamil (TA), Hindi (HI), Spanish (ES), and French (FR).
- 🚨 **Emergency Support Modal**: Quick access to emergency hotlines (108 / 112) and care centers.
- 💾 **Local Storage Persistence**: Client-side persistence for appointment records, doctors, and active session management.

---

## 🛠️ Tech Stack

- **Frontend Framework**: React 18, TypeScript
- **Icons**: Lucide React
- **Styling**: Tailwind CSS
- **State Management**: React Hooks (`useState`, `useEffect`, `useCallback`)
- **Storage**: Browser `localStorage`
